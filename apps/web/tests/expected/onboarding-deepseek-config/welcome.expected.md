  - heading "平台说明" [level=2]
  - paragraph: 本平台是以团队共享方式部署的 DeepSeek Harness 实例。会话、文件与终端都在服务器上，每个账号还可以挂载自己机器上的目录：服务器承载工作区，而你的编辑与命令在挂载的那台设备上执行。
  - paragraph: 挂载目录需要先配对持有该目录的机器：在账号设置中打开配对入口，生成配对码，然后在目标机器上运行服务器给出的 agent 命令。一个配对码可以挂载多台设备，每个挂载目录都会成为一个工作区，你可以在其中新建会话。文件始终留在你的设备上，会话只能访问你挂载的路径，挂载工作区里的终端运行的是那台设备自己的 shell。
  - paragraph: DeepSeek Harness 0.2 仍处于预览阶段，产品功能与插件 API 会继续快速迭代，开发者相关的进阶功能可在配置中开启。
